## 📌 Descripción del Proyecto
Este repositorio contiene el código fuente para el procesamiento ETL, integración de fuentes institucionales y la ejecución del modelo de aprendizaje no supervisado (K-Means) para la segmentación territorial agrofinanciera en Colombia.
